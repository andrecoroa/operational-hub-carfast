# Anexo 1 - Guia rápido Gestão de Tarefas CarFast v2

## Objetivo

Este guia serve para testar o módulo de Gestão de Tarefas da CarFast v2 sem formação prévia.

A aplicação ainda está em fase piloto. O objetivo é perceber se o fluxo é claro, se os campos fazem sentido e se a ferramenta pode ajudar a operação real.

## Acesso

URL:

```text
https://operational-hub-carfast.onrender.com
```

Dados de acesso:

```text
Email: [preencher]
Password: [preencher]
```

Se a aplicação demorar a abrir, aguarda alguns segundos e tenta novamente.

## Onde começar

1. Entrar na aplicação.
2. Abrir o menu `Gestão de Tarefas`.
3. Criar uma nova tarefa ou abrir uma tarefa existente.

## O que é uma tarefa

Uma tarefa representa um pedido, contacto, ação ou situação operacional que precisa de acompanhamento.

Pode ter origem em:

- criação manual;
- e-mail;
- WhatsApp;
- chamada Webex;
- Rentway;
- sistema;
- pedido interno.

Nesta fase piloto, a criação será principalmente manual.

## Campos principais

Preenche apenas a informação disponível.

Não é obrigatório inventar dados para completar o formulário.

Campos úteis:

- origem;
- assunto;
- descrição;
- cliente;
- contacto;
- e-mail;
- telefone;
- matrícula;
- número de reserva;
- número de contrato;
- estação;
- categoria;
- subcategoria;
- prioridade;
- responsável;
- equipa ou departamento/fila;
- data limite.

## Estados disponíveis

Os estados principais são:

- Nova;
- Em análise;
- Em tratamento;
- A aguardar cliente;
- A aguardar interno;
- A aguardar fornecedor;
- Respondida;
- Resolvida;
- Fechada;
- Sem ação necessária;
- Cancelada.

Usa o estado que melhor representa a situação real.

## Como testar uma tarefa

1. Criar uma tarefa com os dados disponíveis.
2. Abrir a tarefa criada.
3. Confirmar se o resumo é claro.
4. Alterar o estado.
5. Alterar responsável ou data limite, se fizer sentido.
6. Adicionar um comentário interno.
7. Fechar a tarefa ou marcar como `Sem ação necessária`, se aplicável.

## Como dar feedback

Durante ou após o teste, regista:

- o que foi claro;
- o que foi confuso;
- campos em falta;
- campos desnecessários;
- estados que não fazem sentido;
- filtros úteis ou em falta;
- dificuldades encontradas.

O objetivo é melhorar a ferramenta antes de a tornar mais completa.
