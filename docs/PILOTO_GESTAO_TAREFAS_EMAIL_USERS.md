## Assunto

Teste piloto CarFast v2 - Gestão de Tarefas

## Email

Olá,

Vamos iniciar um teste piloto da nova plataforma CarFast v2, focado no módulo de Gestão de Tarefas.

O objetivo deste teste não é avaliar o teu conhecimento da aplicação. Queremos perceber se uma pessoa consegue criar, procurar, acompanhar e fechar tarefas operacionais sem explicação prévia.

Este módulo pretende vir a centralizar pedidos e ações que hoje podem estar dispersos por e-mail, chamadas, WhatsApp, Rentway, folhas Excel ou pedidos internos.

Durante este piloto, continua a usar os canais habituais da operação. A CarFast v2 deve ser usada apenas como apoio para testar o fluxo, a organização, os filtros, os estados e a informação necessária.

## Regras do teste

- Usa apenas a informação que tens disponível.
- Não inventes dados só para preencher campos.
- Se um campo não fizer sentido, deixa vazio.
- Se algo for confuso, lento, inútil ou estiver em falta, regista no feedback.
- Se tiveres dúvida durante o teste, usa `Relatar experiência` no final ou comunica essa dificuldade no comentário da tarefa.
- O objetivo é testar a app, não concluir trabalho real.

## Teste 1 - Criar uma tarefa operacional

Objetivo: perceber se a criação de tarefas é clara e se os campos fazem sentido.

1. Entrar na aplicação.
2. Abrir o menu `Gestão de Tarefas`.
3. Criar uma nova tarefa.
4. Preencher apenas a informação que souberes:
   - origem;
   - assunto;
   - categoria;
   - subcategoria, se fizer sentido;
   - cliente;
   - contacto;
   - e-mail;
   - telefone;
   - matrícula;
   - reserva;
   - contrato;
   - estação;
   - responsável;
   - data limite;
   - departamento/fila;
   - descrição.
5. Gravar a tarefa.

No fim deste teste, anota:

```text
Foi fácil criar a tarefa?
O formulário tem campos a mais?
Faltou algum campo importante?
A linguagem usada é clara?
```

## Teste 2 - Gerir o backlog

Objetivo: perceber se a lista, os indicadores e os filtros ajudam a encontrar trabalho.

1. Na página `Gestão de Tarefas`, observa os indicadores:
   - abertas;
   - sem responsável;
   - vencidas;
   - limite hoje.
2. Clica em `Sem responsável`.
3. Clica em `Vencidas`.
4. Usa a pesquisa para procurar por:
   - cliente;
   - matrícula;
   - reserva;
   - contrato.
5. Experimenta filtrar por:
   - estado;
   - categoria;
   - origem;
   - responsável;
   - estação.

No fim deste teste, anota:

```text
Os indicadores ajudam?
Os filtros são fáceis de usar?
Encontraste rapidamente uma tarefa?
Falta algum filtro?
A lista mostra informação suficiente?
```

## Teste 3 - Acompanhar e fechar uma tarefa

Objetivo: validar se a tarefa funciona como um caso operacional.

1. Abre uma tarefa.
2. Confirma se o resumo é claro:
   - origem;
   - estado;
   - categoria;
   - cliente;
   - matrícula;
   - reserva/contrato;
   - responsável;
   - prazo.
3. Atualiza o estado da tarefa.
4. Altera ou confirma:
   - responsável;
   - data limite;
   - categoria;
   - estação;
   - departamento/fila.
5. Adiciona um comentário interno.
6. Se fizer sentido, fecha a tarefa ou marca como `Sem ação necessária`.
7. Confirma se o histórico ficou compreensível.

No fim deste teste, anota:

```text
O detalhe da tarefa é claro?
Os estados fazem sentido?
Percebe-se onde atualizar e onde comentar?
O histórico ajuda?
O que mudarias?
```

## O que queremos aprender

Depois destes três testes, queremos perceber:

- se a Gestão de Tarefas pode funcionar como centro operacional;
- se os campos são suficientes;
- se existem campos a mais;
- se os estados fazem sentido;
- se os filtros ajudam a gerir o trabalho;
- se o detalhe da tarefa parece um caso operacional;
- se a equipa consegue usar sem explicação prévia;
- que melhorias devem ser feitas antes de integrar e-mail, WhatsApp, Webex ou Rentway.

## Duração estimada

Entre 20 e 30 minutos.
